# Character model credits

The three bot characters are free low-poly models from Polyfork, used under
the Creative Commons Attribution 4.0 International licence (CC BY 4.0).
The attribution notice below is baked into each `.glb` file's JSON chunk
(`asset/copyright` and `asset/extras`); it is repeated here so the credit
travels with the repository.

- **Aircrew Pilot** by Polyfork (https://polyfork.dev/asset/aircrew-pilot-e6b732), CC BY 4.0
  — file: `aircrew-pilot-e6b732.glb` — licence: https://creativecommons.org/licenses/by/4.0/
- **Armoured Knight Hero** by Polyfork (https://polyfork.dev/asset/armoured-knight-hero-07121f), CC BY 4.0
  — file: `armoured-knight-hero-07121f.glb` — licence: https://creativecommons.org/licenses/by/4.0/
- **Buddhist Monk** by Polyfork (https://polyfork.dev/asset/buddhist-monk-39f498), CC BY 4.0
  — file: `buddhist-monk-39f498.glb` — licence: https://creativecommons.org/licenses/by/4.0/

Polyfork licence overview: https://polyfork.dev/licensing

The map, weapons, HUD, audio and all other geometry in this game are
original, built from code. Only the three character models above come from
Polyfork, and they are loaded by our own minimal GLB loader
(`game/src/gltf.js`) — no vendor GLTFLoader is used.
